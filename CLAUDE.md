# Content Engine — Project Index

This file must be named exactly `CLAUDE.md` and live in the repo root — Claude Code auto-reads it on every session. Keep this file short. All real instructions live in the clearly-named files below.

## Before writing any blog, read these files in order:

1. **`docs/content-workshop-blog-writer-instructions.md`**
   The full editorial system: voice, intake questions, workflow, SEO rules, style rules, formatting, CTAs, titles, checklists, visual specs. This is the primary reference for every blog.

2. **`docs/content-workshop-editorial-addendum.md`**
   Newer rules still being confirmed from reviewer feedback rounds. Check this after the main instructions file — it can override or add to it. Dated at the top; always check the date.

## Rule

Always load and apply both files above before drafting a blog. If the two files conflict, the addendum wins (it's newer).

## Landing pages

For CW website landing pages, use **`docs/landing-page-template.md`**: section-by-section slots, length targets, a worked example (AI Studio page), and a pre-publish checklist. Voice and name-verification rules from the two files above still apply.
